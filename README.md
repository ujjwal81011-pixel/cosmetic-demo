# 🌸 Luxury Cosmetic Shop Website (Modern & Mobile-Friendly)

A state-of-the-art, high-converting cosmetic shop website designed with luxury aesthetics (Rose Gold, Champagne, Ivory & Noir) and rich interactive features.

---

## ✨ Features Included

1. **Ultra-Modern & Luxury Aesthetic**:
   - Editorial serif headlines paired with ultra-clean modern typography.
   - Glassmorphism, subtle rose-gold glows, and smooth transitions.
   - Designed to captivate beauty and skincare shoppers.

2. **100% Mobile-Friendly & Responsive**:
   - **Mobile Bottom Navigation Bar** with direct icons for Home, Shop, Search, Wishlist, and Cart Bag.
   - **Slide-out Mobile Navigation Drawer** with smooth backdrop blur.
   - Dynamic touch-friendly product card layouts (optimized for small, medium, and tablet screens).

3. **Complete E-Commerce Interactions**:
   - **Slide-Over Shopping Bag Drawer** with quantity selectors (`+` / `-`), free shipping progress bar, promo code engine (try `GLOW20` for 20% off), subtotal, and checkout simulation.
   - **Interactive Beauty Routine Quiz**: 3-step interactive skin diagnosis that matches users to a customized 3-step beauty ritual with 1-click bundle addition.
   - **Quick View Modal**: Pop-up preview with shade selector swatches, active ingredients, and size options.
   - **Live Search Modal**: Search across products, categories, or skin concerns in real time.
   - **Wishlist & Cart Persistence**: Saved automatically to browser `localStorage`.
   - **Multi-Currency Toggle**: Instant switch between `₹ INR` and `$ USD`.

## 🏷️ Customizing The Placeholders

All placeholders in the website are clearly written with square brackets `[...]` so you can effortlessly replace them with your actual brand details:

| Placeholder | Where to Find | Description |
|---|---|---|
| `[YOUR BRAND]` / `[Your Brand Name]` | `index.html`, `app.js` | Your shop or cosmetic brand name |
| `[GLOW20]` | `index.html`, `app.js` | Your promo / discount coupon code |
| `[₹ 1,499]` / `[$ 28.00]` | `app.js` (`PRODUCTS` array) | Product pricing in INR & USD |
| `[Luminous Peptide Glow Serum]` | `app.js` | Your product names |
| `[123 Luxury Beauty Boulevard, Mumbai / New York]` | `index.html` (Contact section) | Your boutique store address |
| `[+91 98765 43210]` | `index.html` (Contact section) | Your official phone / WhatsApp contact |
| `[support@yourbrand.com]` | `index.html` | Your customer support email |
| `@[YourBrandHandle]` | `index.html` (Instagram section) | Your official Instagram or social media username |

## 🚀 How to Run the Website

### Option 1: Double-Click
Simply double-click `index.html` in your file explorer to open it directly in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Live Server / Local Web Server
You can run any simple static server, for example:
```bash
npx serve .
# or
python -m http.server 8000
```
Then visit `http://localhost:8000`.
